TRANSLATOR — CORE COMMANDS REFERENCE
========================================================================

0. DOWNLOAD & INSTALL THE PACKAGE
   composer require ataurbdx/translator

------------------------------------------------------------------------
1. SETUP & INSTALLATION (ON-DEMAND & MODULAR)
------------------------------------------------------------------------

   A. INTERACTIVE INSTALLER (Prompts you to choose features):
      php artisan translator:install

   B. FULL SUITE INSTALLATION (Installs all 5 tables without prompts):
      php artisan translator:install --all
      OR:
      php artisan translator:install --type=all

   C. MINIMAL CORE INSTALLATION (Languages & Settings only):
      php artisan translator:install --type=core
      • Installs: translator_languages, translator_settings
      • Best for: Projects using Type 1 (Inline JSON), File, JSON, or pure AI. Zero extra database bloat!

   D. TYPE 2: INTERNAL DYNAMIC MODELS ONLY:
      php artisan translator:install --type=internal
      • Installs: translator_languages, translator_settings, translator_dynamics
      • Best for: Polymorphic translations on small/medium Eloquent models.

   E. TYPE 5: STATIC UI STRINGS ONLY:
      php artisan translator:install --type=static
      • Installs: translator_languages, translator_settings, translator_statics
      • Best for: Translating web UI, buttons, navbar, forms, and headers via DB.

   F. TYPE 8: CULTURAL LOCALES & NUMBERS ONLY:
      php artisan translator:install --type=local
      • Installs: translator_languages, translator_settings, translator_locales
      • Best for: Bengali numerals (২০২৬), South Asian Lakh/Crore formatting, dates, number-to-words.

   G. COMBINED CUSTOM SELECTION (Multi-type):
      php artisan translator:install --type=static,local

------------------------------------------------------------------------
2. ON-DEMAND TABLE GENERATORS (FOR HIGH-VOLUME / LARGE PROJECTS)
------------------------------------------------------------------------

   A. TYPE 3: GENERATE DEDICATED EXTERNAL TABLE (for high-traffic model):
      php artisan translator:make:external listings
      • Creates: database/migrations/..._create_translator_listings_table.php
      php artisan migrate

   B. TYPE 4: GENERATE GROUPED HYBRID TABLE (for domain clusters):
      php artisan translator:make:hybrid worlds
      • Creates: database/migrations/..._create_translator_worlds_table.php
      • Shared across: Country, State, City, SubCity in 1 table!
      php artisan migrate

   C. TYPE 1: CONVERT COLUMN TO INLINE JSON:
      php artisan translator:make:inline products description
      php artisan migrate

------------------------------------------------------------------------
3. UTILITY & AI COMMANDS
------------------------------------------------------------------------

   A. EXPORT LOCALE RULES TO JSON FILE (3-Tier Fallback: DB -> File -> Code):
      php artisan translator:export-locales
      php artisan translator:export-locales --locale=bn
      php artisan translator:export-locales --force

   B. AI AUTO-TRANSLATE MISSING KEYS (Google Gemini / OpenAI / DeepL):
      php artisan translator:ai-sync --from=en --to=bn
      php artisan translator:ai-sync --from=en --to=bn --group=button

   C. VERIFY INSTALLATION & TABLES STATUS:
      composer show ataurbdx/translator
      php artisan migrate:status

   D. RE-PUBLISH CONFIG FILE ONLY:
      php artisan vendor:publish --provider="Ataurbdx\Translator\TranslationServiceProvider" --tag="config"

   E. CLEAR & REBUILD CONFIG CACHE:
      php artisan config:clear
      php artisan config:cache

------------------------------------------------------------------------
4. UPGRADE & UNINSTALL
------------------------------------------------------------------------

   UPGRADE:
      composer update ataurbdx/translator
      php artisan migrate

   UNINSTALL:
      composer remove ataurbdx/translator

------------------------------------------------------------------------
5. GIT VERSION TAGGING & DETECTION (FOR PACKAGE DEVELOPERS)
------------------------------------------------------------------------

   A. DETECT LATEST RELEASE TAG (Instant check):
      git describe --tags --abbrev=0

   B. VIEW LATEST TAG WITH COMMIT MESSAGE:
      git tag -l --sort=-v:refname -n1

   C. LIST ALL TAGS IN DESCENDING ORDER (Newest first):
      git tag --sort=-v:refname

   D. CREATE & PUSH A NEW RELEASE TAG:
      git add .
      git commit -m "feat: your update message"
      git push origin main
      git tag v1.0.7
      git push origin v1.0.7

   E. DELETE A WRONG TAG (If you made a typo):
      git tag -d v1.0.X
      git push origin --delete v1.0.X

========================================================================
TABLES SUMMARY
========================================================================
Core Tables (Always available on demand):
  • translator_languages  (Supported languages, flags, defaults)
  • translator_settings   (AI API keys, cache rules, headless API settings)

Feature Tables (Install on demand when needed):
  • translator_dynamics   (Type 2: Polymorphic dynamic model translations)
  • translator_statics    (Type 5: Database UI strings, buttons, menus)
  • translator_locales    (Type 8: Cultural rules, digits, calendar, money-to-words)

Dedicated Scaling Tables (Generated on demand):
  • translator_{model}    (Type 3: Dedicated external table per high-volume model)
  • translator_{domain}   (Type 4: Hybrid domain cluster table)
